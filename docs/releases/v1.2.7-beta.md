# V1.2.7 Beta candidate — not published

Version code 47. Base: main at 442ea5315967f5e1cb4b9dae2b8cb28241e2a8fb.

Adds the approved language selector in Bài học and Mandarin A1/A2 with simplified Hanzi, Pinyin and Vietnamese explanations. Initial content: 25 topics, 200 unique speaking lines, 100 scripted exchanges, 25 short readings (100 sentences reused from the speaking lines), 75 reading comprehension questions and 100 translation exercises (also drawn from the speaking lines). Progress and diamond scores are isolated by language-prefixed IDs in each profile and included in the existing authenticated cloud sync.

Mandarin playback uses installed offline mainland Chinese TTS data; users can audition/select a voice. Recognition requests zh-CN. Character matching is textual feedback, not an acoustic or tone score. Temporary voice recordings preserve the existing foreground/RAM-only lifecycle. The English name recognizer, approved home/check-in layout, original signing configuration, application ID and published update index are unchanged.

No APK release, upload to Releases or main merge is authorized by this candidate work. See docs/curriculum/chinese-a1-a2.md for scope and verification limitations.
