# Approved language entry typography — 1.2.9 candidate

Approved by the user on 28 November 2026 after the portrait demo:
“Làm đúng theo demo đã duyệt ở trên. Giữ nguyên bố cục, giọng văn, định dạng.
Chỉ mở rộng thêm nội dung đã thông qua, tuyệt đối không thay đổi bất cứ thứ gì đã duyệt.”

Only the language entry's three headings change. Speakivra uses the existing official
italic wordmark mask, with a cyan/blue/purple light sweep travelling left to right
inside the letters. The symbol stays still. English and Chinese titles use solid
heavy sans-serif letters, silver faces on dark backgrounds, cyan bevels and shallow
purple extrusion; navy faces keep contrast on the existing light surface. The rest
of the app retains Nunito. Vietnamese accents and accessible text remain real text.

The same logo, two cards, icons, wording, order, spacing, padding and selection
callbacks remain. Wordmark occupies a 64dp-high heading slot and fits its original
transparent image aspect ratio; titles shrink only when needed to fit their existing
column at narrow widths or large font scales. Neither the learner picker nor home,
check-in, programmes, progress, cloud sync, APK signing or update feed is changed.

Review actual APK captures 180–184 in all three appearances, two sweep phases and
large type, alongside the approved demo. Tests check that the light changes letter
pixels only, the logo is stationary, both cards still select their own language and
titles fit at widths 320/360dp and font scales 1.0/1.5. The existing full suite is kept.

This is a development candidate, not a release. The notification demo is a separate
proposal; this typography approval does not add or publish background update alerts.
