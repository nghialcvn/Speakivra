- Khắc phục chức năng **Kiểm tra bản cập nhật**: nếu GitHub Releases API tạm thời không phản hồi hoặc bị giới hạn số lần truy cập, ứng dụng thử nguồn danh mục phiên bản dự phòng trên chính repository Speakivra.
- Nguồn dự phòng chỉ cung cấp metadata chính thức. App vẫn kiểm tra tag, URL APK, mã SHA-256, applicationId, versionCode và chứng thư ký trước khi cho cập nhật đè.
- Thông báo cụ thể hơn khi lỗi DNS, hết thời gian kết nối hoặc GitHub giới hạn lượt kiểm tra; không che mọi lỗi thành một thông báo chung.
- Có nút **Mở GitHub Releases để tải thủ công** khi không nhận được danh sách bản cập nhật.
- Workflow phát hành đồng bộ danh mục cập nhật dự phòng sau khi công bố APK được ký và kiểm thử. Không tải hoặc cài đặt từ nguồn ngoài repository chính thức.
- Giữ nguyên Neon đã duyệt ở V0.1.16, các lựa chọn giọng Anh-Mỹ/Anh-Anh, giọng nam/nữ, dữ liệu học, hồ sơ, khóa ký và cơ chế cập nhật an toàn.
